# Dependencies

MCP Abilities - Check Runner depends on three runtime systems. Each link goes to the authority for the named dependency.

- [WordPress 6.9 or newer](https://wordpress.org/download/) provides the Abilities API used to register the release check.
- [PHP 8.0 or newer](https://www.php.net/supported-versions.php) provides the required server runtime.
- [Plugin Check](https://wordpress.org/plugins/plugin-check/) provides the official checks and runner.

Install and activate Plugin Check before this add-on.
